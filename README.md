**Десктопное приложение для контроля лечения хронических заболеваний и связи «врач — пациент».**

## 📋 О проекте

Пациенты с хроническими заболеваниями (гипертония, диабет, ишемия) вынуждены постоянно
принимать лекарства и следить за самочувствием. Врач видит их только на приёме —
раз в несколько недель. Между визитами динамика теряется, а бумажные дневники неудобны
и часто теряются.

**«Дневник терапии»** решает эту проблему: приложение связывает пациента, врача
и администратора в единой системе. Все данные сохраняются в базе, врач видит динамику
в реальном времени и может корректировать лечение.

## ✨ Возможности

### 👤 Пациент
- Ведение ежедневного дневника самочувствия
- Выбор симптомов, интенсивности, триггеров из готовых списков
- Внесение показателей здоровья: давление, пульс, сахар, температура, рост, вес
- Просмотр плана лечения и истории записей
- Личный профиль с данными и лечащим врачом

### 🩺 Врач
- Список прикреплённых пациентов
- Создание новых пациентов с автогенерацией логина и пароля
- Назначение лечения: препарат, дозировка, кратность, период
- Поиск препаратов и добавление своих в справочник
- Просмотр дневников в виде карточек
- Постановка диагноза по МКБ-10
- Горячие клавиши для быстрой навигации

### ⚙️ Администратор
- Управление пользователями: создание, редактирование, удаление
- Генерация логинов и паролей
- Сброс паролей с копированием в буфер обмена
- Прикрепление пациентов к врачам
- Аналитика с диаграммами (пациенты по врачам, приверженность лечению, динамика дневника)
- Экспорт аналитики в PDF

### 🎨 Общее
- Светлая и тёмная темы с сохранением выбора
- Современный интерфейс с карточками и тенями
- Анимированные интерактивные пузырьки на экране входа

## 🚀 Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/lllizaveta-kr/diary-therapy.git
cd diary-therapy
```

### 2. Установить зависимости

```bash
pip install PySide6 mysql-connector-python
```

### 3. Настроить подключение к БД

Скопируйте `config.example.py` в `config.py` и укажите свой пароль от MySQL.

### 4. Запустить приложение

```bash
python main.py
```
