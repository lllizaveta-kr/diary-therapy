## 📖 О проекте

«Дневник терапии» — это учебный проект, разработанный на Python с использованием PySide6 и MySQL. Приложение автоматизирует процесс ведения медицинских записей, позволяет врачам назначать лечение, пациентам — отслеживать своё состояние, а администраторам — управлять пользователями и просматривать статистику.

### 🎯 Основные возможности

- **Авторизация** с хешированием паролей (SHA-256) и разграничением прав доступа.
- **Три роли:** администратор, врач, пациент — каждая со своим интерфейсом и функционалом.
- **Дневник самочувствия:** пациенты записывают симптомы, показатели (давление, пульс, сахар, температура, рост, вес), триггеры и заметки.
- **Назначения:** врачи создают назначения с выбором препарата из справочника, дозировкой, кратностью и периодом приёма.
- **Справочник МКБ-10:** врачи могут ставить диагноз, выбирая болезнь из классификатора.
- **Аналитика для администратора:** графики (пациенты по врачам, приверженность лечению, активность в дневнике), экспорт в PDF.
- **Тёмная тема:** переключение светлой/тёмной темы оформления.
- **Горячие клавиши:** F1 — помощь, Ctrl+Q — выход, Ctrl+1..5 — навигация по разделам.
